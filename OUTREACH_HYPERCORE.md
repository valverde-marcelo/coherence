# Outreach — Hypercore Protocol team

Objective: get **Coherence** noticed by the Hypercore Protocol community and
maintainers, so it can be featured in their showcase/blog/social channels.

> Status: **draft — not sent yet.** The outreach message below is ready to be
> sent manually by the project author through the preferred channel.

## Why it fits

- Coherence is a real-world, end-user desktop app built directly on
  **Hypercore / Hyperbee / Hyperswarm / Corestore** (the Holepunch stack) — the
  exact kind of "batteries-included" use case the protocol website highlights.
- It is **MIT/Apache-2.0 licensed** like the ecosystem, free, open-source, and
  has a public repo + landing page.
- It demonstrates: identity, signed append-only logs, transitive social graph,
  identity recovery via seeders — all P2P with no central servers.
